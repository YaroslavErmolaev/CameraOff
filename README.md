# CameraOff

![macOS](https://img.shields.io/badge/macOS-13%2B-black?logo=apple)
![Swift](https://img.shields.io/badge/Swift-5-orange?logo=swift)
![License](https://img.shields.io/badge/license-Unlicense-blue)

**CameraOff** — небольшая утилита для macOS, которая позволяет быстро отключать доступ к камере на уровне системы и управлять этим состоянием прямо из строки меню.

Приложение работает как menu bar utility: не показывает окно и не занимает место в Dock.

## Возможности

- 🔴 красный индикатор в строке меню — камера включена;
- ⚪️ серый индикатор — камера отключена;
- включение и отключение камеры из меню;
- автоматическое отслеживание текущего состояния;
- запуск приложения при входе в macOS;
- быстрый переход к системному управлению профилями;
- работа без отдельного главного окна;
- поддержка macOS 13 и новее.

## Как это работает

macOS не предоставляет обычному приложению публичный API, который позволял бы незаметно и мгновенно запрещать использование всех камер всем остальным приложениям.

Поэтому CameraOff использует системный Configuration Profile с ограничением:
```xml
<key>allowCamera</key>
<false/>
```

Профиль использует payload `com.apple.applicationaccess` и запрещает доступ к камере на системном уровне.

### Отключение камеры

При выборе **«Выключить камеру…»** приложение:

1. создаёт configuration profile;
2. открывает его средствами macOS;
3. переводит пользователя в системные настройки для подтверждения установки;
4. автоматически обнаруживает установленный профиль;
5. меняет индикатор в строке меню на серый.

Подтверждение установки требуется самой macOS и не может быть корректно обойдено обычным приложением без MDM или приватных API.

### Включение камеры

При выборе **«Включить камеру»** CameraOff пытается удалить созданный им профиль.

Если macOS требует ручного подтверждения, приложение автоматически открывает соответствующий раздел System Settings.

## Индикатор состояния

| Индикатор | Состояние |
| --- | --- |
| 🔴 Красный | Камера доступна приложениям |
| ⚪️ Серый | Камера отключена профилем CameraOff |

Состояние установленного профиля проверяется автоматически, поэтому индикатор обновляется даже после изменений, сделанных непосредственно в System Settings.

## Автозапуск

Пункт **«Запускать при входе»** использует современный API macOS:

```swift
SMAppService.mainApp
```

Если система требует дополнительного разрешения, CameraOff открывает раздел **Login Items** в System Settings.

## Требования

- macOS 13 Ventura или новее;
- Xcode с поддержкой соответствующей версии macOS;
- Swift 5;
- для фактического отключения камеры пользователь должен подтвердить установку configuration profile.

## Сборка

Откройте:

```text
CameraOff.xcodeproj
```

или workspace:

```text
CameraOff.xcworkspace
```

Выберите схему **CameraOff** и запустите проект обычной командой **Run** в Xcode.

Проект также можно собрать из Terminal:
```bash
xcodebuild \
  -project CameraOff.xcodeproj \
  -scheme CameraOff \
  -configuration Release \
  build
```

### Основные компоненты

- **CameraProfileController** — создание, обнаружение и удаление системного профиля ограничения камеры;
- **StatusBarController** — меню и индикатор состояния в строке меню;
- **LaunchAtLoginController** — управление автозапуском через `SMAppService`;
- **AppDelegate** — связывает компоненты приложения;
- **main.swift** — запускает приложение в режиме accessory без Dock-иконки.

## Ограничения

CameraOff не изменяет TCC-базу, не завершает системные процессы камеры, не модифицирует драйверы и не использует приватные API.

Это сделано намеренно: подобные обходные способы нестабильны, требуют повышенных привилегий и могут перестать работать после обновления macOS.

Configuration Profile остаётся наиболее предсказуемым системным способом глобально ограничить использование камеры на обычном Mac.

## Конфиденциальность

CameraOff:

- не получает изображение с камеры;
- не записывает видео или звук;
- не отправляет данные в интернет;
- не требует учётной записи;
- работает локально на Mac.
